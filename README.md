# CineSense — Movie Review Classification

A student-friendly Machine Learning project that classifies an English movie review as **positive** or **negative** using TF-IDF and Logistic Regression, with a responsive Streamlit web interface.

## Project structure

```text
Movie_Review_Classification_Project/
├── app.py
├── train_model.py
├── requirements.txt
├── README.md
├── PRACTICAL_FILE.md
├── .gitignore
└── artifacts/                 # created after training
    ├── sentiment_model.joblib
    └── metrics.json
```

## 1. Run locally on your laptop

Install Python 3.10 or newer. Open a terminal in this folder and run:

```bash
python -m venv .venv
```

Activate it:
- Windows: `.venv\Scripts\activate`
- macOS/Linux: `source .venv/bin/activate`

Install packages and train the model:

```bash
python -m pip install -r requirements.txt
python train_model.py
```

The first training run downloads the NLTK `movie_reviews` corpus. An internet connection is needed for this initial download. It creates the `artifacts/` folder.

Launch the website:

```bash
streamlit run app.py
```

Open the local URL printed by Streamlit, usually `http://localhost:8501`.

## 2. Show the project on your mobile

### Recommended: deploy online
1. Create a GitHub account/repository and upload `app.py`, `train_model.py`, `requirements.txt`, `README.md`, and the generated `artifacts/` files.
2. Keep `artifacts/sentiment_model.joblib` and `artifacts/metrics.json` in the repository. They are generated by training and are required by the app.
3. Sign in to Streamlit Community Cloud and deploy the repository, selecting `app.py` as the main file.
4. Open the deployed public URL on your phone. Test it using mobile data or Wi-Fi.

Do not upload private credentials or secrets. The trained model file is a project artifact, not a secret. Public hosting and repository settings may change; follow the current platform prompts.

### Quick demo on the same Wi-Fi (without deployment)
Run:
```bash
streamlit run app.py --server.address 0.0.0.0
```
Find your laptop's local IPv4 address using `ipconfig` on Windows. On the phone connected to the same Wi-Fi, open `http://LAPTOP_IP:8501`. Firewall settings may need to allow the connection. This local address is not accessible from outside your network.

## 3. How the ML model works

1. The NLTK movie_reviews corpus supplies labeled positive and negative reviews.
2. `train_test_split` reserves 20% for testing and uses stratification to preserve class proportions.
3. `TfidfVectorizer` converts text into numeric word and two-word phrase features.
4. `LogisticRegression` learns a decision boundary between the two sentiment classes.
5. The test split is used to calculate accuracy, classification report and confusion matrix.
6. Streamlit loads the saved pipeline and predicts sentiment for a new review.

## 4. Important notes
- This is a binary classifier for **English-language** reviews.
- Confidence is an estimated class probability, not a guarantee of correctness.
- The NLTK movie_reviews corpus is relatively small compared with modern datasets; results on new reviews may differ.
- Always train the model before running the app.
- For a fair evaluation, do not train on the test set or report a made-up accuracy. Use the value printed by `train_model.py` / shown in the app.
